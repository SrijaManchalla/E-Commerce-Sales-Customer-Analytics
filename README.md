# E-Commerce Sales & Customer Analytics
A Power BI dashboard created to analyze e-commerce sales, customers, products and returns.

## About the Project
I created this dashboard using Power BI to understand the sales and customer data of an e-commerce business.
It includes:
- Total revenue
- Total orders
- Total customers
- Units sold
- Average order value
- Sales by month, category and region
- Customer analysis by age and gender
- Product sales and returns

## Tools Used
- Power BI
- DAX

## Key Findings
- Electronics has the highest revenue.
- South has the highest revenue among the regions.
- Male and female customers have similar revenue.
- Fashion has a higher return rate compared to other categories.
- Average order value is different across age groups.

## Dashboard
The project has 3 pages:
1. Executive Overview
2. Customer and Product Insights
3. Key Insights and Recommendations
